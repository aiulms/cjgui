# CJGUI 对外简介

用于仓库简介和项目展示。能力与验收范围以 [当前开发状态](../runtime/cjgui/ACTIVE_DIRECTION.md) 为准。

## 简短介绍

面向人和 AI 共同工作的仓颉自绘 GUI 框架。以 Metal 驱动桌面界面，让人通过窗口交互，让 AI 通过结构化对象、上下文和授权动作参与同一应用。macOS 优先，开发预览中。

## 完整介绍

CJGUI 是一个面向人和 AI 共同工作的仓颉自绘 GUI 框架，以高性能和低延迟为目标。仓颉负责组件、布局和交互，Metal 负责场景合成，AppKit 提供 macOS 窗口与系统文字服务。

人通过视窗理解、选择和编辑；AI 通过与界面对应的结构化对象、上下文和授权动作，读取、修改及批量处理数据。双方操作同一份应用内容，能够接续彼此的工作。聊天界面、模型、Agent 与连接方式由应用开发者选择。

当前已有可组合布局、文字与表单编辑、虚拟列表、指针与焦点交互、共享操作协议及普通 macOS 应用入口，正通过规则编辑器、文档窗口和独立消费者持续完善。macOS 优先，基于 Cangjie 1.1.3，处于开发预览阶段；公共 API、动态组合与端到端交互验证仍在推进。详见仓库 README。
