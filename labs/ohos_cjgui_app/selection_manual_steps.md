# C selection/组合态 人工核验步骤（单次，约 2 分钟）

应用已启动（pid 见下），处于 100% 布局状态。
需要：一台可用鼠标/键盘操作模拟器窗口的电脑（模拟器窗口保持前台）。

1. 在模拟器自绘场景中，**点击「名称」字段**（卡片内第一个输入框，
   当前显示「我的设备」）。
   - 成功信号：屏幕底部状态栏出现
     `editing counter-name: 已聚焦，请直接打字（回车提交）`。
   - 若 1～2 秒内未出现该字样，再点一次字段行即可（聚焦有重试）。
2. 用键盘键入含 emoji 的文本：`测试🚀abc`
   → 观察自绘场景中「名称」字段的文字随输入**实时更新**（本地预览路径）。
3. **长按**已输入文本中的任意字符 → 拖动选择手柄选中一段
   → 观察自绘场景中的**选区高亮**（渲染层 selStart/selEnd 路径）。
4. 按**回车**（显式提交）或点击场景空白处（失焦提交）→ 草稿提交到 owner。
5. 完成后告知执行 AI，由执行者立即跑 transport 读回并归档
   `selection_manual_evidence.md`（核对 name 与键入文本逐码元一致，含 emoji）。
