# 大阶段：局部场景提交与实际应用性能

2026-09-13，原执行任务 Terra/xhigh、原目录。指导已读可复用控件交付与相关源码，接受已列构建/公开消费/普通窗口证据的范围，未独立重跑测试；物理 IME、VoiceOver、真实模型调用与呈现仍未验。

## 目标与取舍

把“修改一个组件”在自绘提交路径的实际工作量降下来，交付通用能力及两种正常应用证据。依据[设计导航](DESIGN_INTENT_INDEX.md)、[渲染资源阶段](2026-09-13-render-resource-efficiency-milestone.md)和[避坑原文](../research/gui-framework-pitfalls-intelligence.md)中的无谓重绘、所有权、缓存失效和事件交错教训。复用既有仓颉布局/场景、组件稳定身份、刷新事务、native staging、纹理缓存和 GPU in-flight 引用；不引入第二运行时或让原生对象成为公开 API。

六主线中组件/布局和人侧输入已有推进；当前回到高性能自绘主线。此前少发 FFI setter 的收益不等于少做 native 工作：CjguiCloneComposableSceneNode 仍逐节点分配并复制属性。先测真实成本，再优化；不是预设全引擎重写或强制损伤区域渲染。长文本尾部、系统输入未验和历史 Escape69 保留，不要求先清零。

## 必要旧问题随本阶段处理

- 续写解析的 `current.value` 来自 nativeInputScene，并非实时 owner 读回；注释不能宣称仅凭该比较证明外部写入被拒绝。用真实 controller/owner 复现：已接受本地 a、旧场景排队 ab，外部同对象替换分别在刷新前后到达；包括写成不同值、写回相同值但版本变化、失焦后重新聚焦、重绑/只读。核对正常调度先后与 owner 的冲突判断；需要修复时使用明确编辑/内容代际或可信来源，不能靠字符串相等把任意旧事件升级为续写，也不能再丢连续输入。已有外部删除测试保留。测试只覆盖实际可达路径，不为假设无限造状态机。
- syncProjection catch 范围包含 native 接受后的 commit/焦点恢复；核实 commit/rollback 的异常契约，不能在 native 已接受后声称旧 scene 已恢复。准备阶段处理可失败工作，提交阶段尽量只做已准备对象交换；对应用回调异常明确结果。不要尝试捕获致命 Error 或伪造回滚成功。
- 通用 bound field 的校验文案当前按错误码猜测并硬编码中文。提供应用可指定的显示文案或格式化入口，保留机器错误码及默认兼容行为；用不同文案的消费者证明无需改框架。不是全面国际化项目。

## 主要代码交付

1. 用现有正常 Host 和两种消费者建立相同负载基线：局部文字/颜色改变、组件增删重排、图片替换、滚动、resize、无变化刷新。记录实际物化节点数，在现有容量内用小/中/近上限至少三个规模。区分 build/layout、FFI setter、native clone/分配、遍历/编码、GPU 提交与异步完成；不能把嵌套计时相加或把计数减少称端到端提速。
2. 针对已证实主要重复成本，实施有界且可解释的增量场景准备/提交。优先稳定身份的不可变数据复用或写时复制等最小方案，明确场景代际与内容数据分离，重排/删除/复用槽位不串命中、焦点、AX和外部关系。保持 candidate 与 accepted 隔离、失败恢复、旧 in-flight GPU 资源存活；不得通过直接修改活 scene 换取少复制。无需强求容器索引完全 O(1)，但不能保留逐节点昂贵对象复制后只报告少 setter。
3. 根据基线处理绘制编码/文本 overlay 重复工作。适合批处理时保持透明度、裁剪、绘制顺序与图片纹理切换；适合局部失效时正确处理移除、遮挡、滚动和 resize。若某项成本不占主导，记录数字和取舍，集中交付主要路径，避免无依据扩展。
4. 两个真实应用用正常公开入口消费最终路径；独立 Luna/Terra 在写集隔离条件下验证一处局部改动、重排、失败重试、外部修改/读回、正常关闭。示例不是 renderer 私有测试入口。保持现有容量/协议兼容，内部 ABI 变化成对更新；新公开接口只在必要时增加并标实验等级。

## 验收与持续执行

相同输入/预热/构建条件前后各至少30个有效样本，报告 p50/p95 与节点复制/分配/提交、队列和资源数，再做空闲恢复。原始日志标源码/产物身份、运行入口/参数和失败项；不得沿用未包含最终改动的样本冒称最终结果。受控 native 像素或渲染比对覆盖透明/裁剪/重排与失败后旧画面；正常应用操作证据另列。presentation unavailable 继续如实记录，GPU completed 不等于人已看见。

按 AGENTS 做相关 core/runtime/native/Host 回归、1.1.3 build --skip-script、公共声明/FFI影响与 diff 检查；不按每个小修重复全套。CodeLattice live root 当前拒绝访问，用允许索引或源码补证，不绕过限制。工具链可疑缺陷先最小复现、更新既有问题账本并向指导报告，保留 workaround 移除条件；对外提交遵循已有授权。

锁屏跳过依赖桌面的验收，继续代码和独立负载工作；不关闭用户 RuleSet 实例，以隔离 bundle ID/临时数据验证。两次实际失败后按既有 K3 升级规则，环境不可用不反复撞。原目录、不切分支、不 stage/commit/push/发布，不改安全设置。完整阶段或实质阻塞主动报告指导，不能只做旧问题修复或基线测试便结束。
