应用开发者能用仓颉组件组合工具菜单、锚定弹层和带表单的对话框，复用现有布局、自绘、焦点、文字输入和真实业务操作。层打开、遮挡、关闭及外部更新后，人和外部调用者仍能识别正确对象、上下文和可执行动作；无需为每个应用写原生菜单/编辑器分支。

## 必要集合修正与补证

1. 当前 anchorKey 只在 reveal/moveFocus 设置，布局按旧像素偏移算范围，尚未看到动态数据变更后根据 anchorKey 重新定位。复现首行前插入/删除、重排/过滤、anchor 被删时的画面与选中/焦点；以稳定 key 和行内偏移恢复，明确 key 消失策略。不能用每次滚动回选中项掩盖丢锚点。
2. materializeVirtualList 遇空 key 直接不加 child，随后普通纵向布局会压缩空位，注释“留下空洞”与路径不符。固定行高 API 还需明确 buildRow 返回不同高度、嵌套子树与重复 key/nodeId 的处理。用缺失中间行、重复身份、超高行、部分行偏移且 overscan=0 验证位置/命中/可见尾行；选择明确失败或正确占位/约束，不能把后一项挪到前一项位置，也不靠固定探针7行结果决定正确范围。
3. 当前 100 条批次是在显示 94–100 后修改 1–100，包含可见目标，不能称100条全部屏外。用临时至少120项或其他合法规模，先记录真实可见/物化范围，动态选出100个与物化目标不相交的授权对象，再一次调用、读回、显露并人接续；原100条批次成功证据保留。错误 capability 不代替“有效 capability 中含未授权目标”的检查，后者需要单独拒绝且不部分写入。
4. 前置普通窗口实际101项，2000项是布局探针；继续分开标记。在领域合法容量内补一次上千条普通窗口滚动/增删/键盘行为，不能把探针数量写成实窗规模。领域导航/GET_CONTEXT 的全量成本仍如实保留。

以上问题先复现，只有相关依赖工作受阻，浮层组件可以独立推进。

## 新能力：一个通用层体系的完整消费

### 一、层组合与布局

提供实验性层容器/宿主及稳定 layer 身份，支持普通内容之上的锚定弹层和居中对话框，组合已有按钮/输入/列表。层顺序、可见性、裁剪与命中使用同一场景，坐标来自实际布局。锚点靠近窗口边缘时选择合理翻转/限宽或裁剪，resize/滚动/锚点消失时按明确策略重定位或关闭。

至少支持一个对话框中再打开一个局部菜单的组合，限定层深度/节点预算，关闭父层收回子层。复用资源/样式，避免层内容泄露或遮挡顺序与语义顺序不一致。不要为新层绕开已有节点数限制或输入版本检查。

### 二、菜单、对话框与输入生命周期

在层宿主上提供可复用的菜单和对话框组件/辅助入口。菜单支持方向键选择、Enter 激活、Escape 关闭和点击外部按策略关闭；禁止项可解释，关闭点击不能误触底层按钮。对话框支持默认初始焦点、范围内 Tab 导航、Escape/显式取消策略、关闭后恢复仍有效的触发控件焦点。文本键盘命令和输入法组合不得被菜单抢走。

打开/关闭/替换层时，旧排队输入、鼠标捕获、选区、命令绑定和缓存必须按身份退场。层内编辑复用领域草稿与验证；外部更新同一对象后按既有版本/冲突规则处理，不能另存一份独立可写的业务镜像。组合态所在层被关闭的提交/取消策略明确并有探针；物理IME验收仍单列。

### 三、语义与授权分开

公开投影描述必要的层类型、归属/锚点、当前交互范围和关闭/执行动作，外部能理解正在编辑什么及缺什么信息。可见节点与遮挡/焦点范围必须对应实际层，不伪造人已经看见；继续区分领域版本、投影和提交/绘制进度。

**模态只约束人的窗口交互，不自动增加外部业务权限门槛。** 有效授权已经覆盖目标/参数和必要确认时，外部可直接执行真实动作，界面据领域结果更新或关闭相应层；不因有弹窗重复请示。缺少必需参数、真实业务条件不满足、权限不足或版本冲突仍要拒绝/等待，不猜用户选择。应用定义这些条件，框架不能把 visible/enabled/authorized 合成一个 Bool。

区分对层的视觉动作和对业务对象的结构化动作：视觉点击必须遵守遮挡和当前层身份；屏外已授权记录的业务操作仍可继续。公开客户端沿现有协议消费，若新增字段/动作说明要有兼容策略，不引入模型运行时。

### 四、两个正常应用与完整验收

规则集使用通用菜单承载现有外观/列表动作，并用通用对话框组合现有规则草稿编辑；文档使用同一层宿主/组件承载现有文档选择、参数输入或其他已有操作。具体最小重组由执行AI决定，不为验收创造重复确认流程。默认无外部连接的正常应用仍可操作。

验证鼠标打开、键盘导航、层内文字/Tab、子菜单、Escape/取消/应用、焦点恢复；锚点移除、底层行复用、resize与外部更新时不串对象。至少一条完整周期：人打开层编辑→外部读当前对象/上下文→已授权操作或明确缺参/冲突→层反映真实结果→人继续；另测背景视觉点击被阻挡但合法屏外结构化操作不被错误禁止。

允许无实现上下文 Luna/Terra 仅用公开说明、CLI/API、descriptor 做一次独立动态发现/操作验收；必须返回实际执行者身份与证据，不拿执行AI手写客户端替代。依赖桌面的项目遇锁屏就先跳过，完成层布局、事件队列、焦点/权限边界、core协议、构建等独立工作。
