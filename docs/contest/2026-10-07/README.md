# CJGUI 初赛作品介绍

**你在界面里改，AI 接着做；AI 做完，你还能接着改。**

CJGUI 是以仓颉为核心的自绘 GUI 框架。它让人的窗口操作、AI 的工具调用和生成面板使用同一份应用数据与规则。开发者可以开放当前对象、字段和动作，让 AI 的工作直接进入应用；用户在界面里看见结果，继续处理。

界面也可以参与协作：保留开发者写好的主界面，再按任务生成一块可操作的面板。生成控件绑定应用已有的字段和动作，人可以直接使用它们。

## 先看这个场景

打开[约 2 分 15 秒的参赛演示](demo/README.md)，从 00:41 看任务面板：

1. 人点击提交，手写区和生成区的标题一起变为只读。
2. 外部工具追加备注，两边显示同一份新内容。
3. 工具尝试修改已冻结标题，应用拒绝修改并保留原标题。

这个场景展示了 AI 工具接入应用的基础：有可发现的操作、有共同的数据、有一致的业务规则，结果能在正常窗口里看到。本次使用公开脚本客户端验证入口，真实大模型经工具适配接入后的效果另行评测。

视频还展示编辑器首页的真实滚动与 Markdown 排版，以及鸿蒙温控和编辑器的模拟器画面。
