# CJGUI 自选命题项目提案

作品名称：CJGUI

报名命题：CJGUI：面向人和 AI 共同构建与操作界面的仓颉自绘 GUI 框架

类别：自选命题；应用框架。初赛版本：2026 年 10 月 7 日开发预览。

## 让人和 AI 在同一个应用里接着做事

**你在界面里改，AI 接着做；AI 做完，你还能接着改。**

这是 CJGUI 想带给应用的协作方式。人在窗口里选择内容、修改字段、推进任务；AI 经授权读取当前内容，调用应用提供的操作，把修改直接交回正在使用的界面。双方面对同一份数据，遵守同一套规则。

协作也可以改变界面本身。应用保留开发者写好的主界面，同时开放一块生成区。AI 可以根据任务组合字段、按钮和面板，让需要的操作出现在手边；生成控件继续使用应用已有的数据和业务规则。人可以接着使用这些控件，也可以回到原有界面。

我们以仓颉为核心实现这套自绘 GUI 框架，面向编辑器、配置工具、数据工作台和需要接入 Agent 的应用开发者。希望开发者在做出一个好用界面的同时，也能让 AI 理解这个应用、参与其中的工作。

## 从一个任务面板看协作价值

演示中的任务同时出现在手写区和生成区。人点击“提交当前任务”，两边的标题立即变成只读；外部工具随后追加备注，两个区域显示同一份新内容；再尝试修改已提交的标题，应用拒绝这次操作，原标题保留。

这段演示把协作中最容易含糊的事情说清楚了：改动确实进入了应用，界面能看到结果，业务规则对两种入口都生效。开发者可以据此把 AI 工具接进自己的工作流，用户也能继续检查和处理结果。

| 工作过程 | 应用里的结果 | 协作价值 |
| --- | --- | --- |
| 人在生成面板提交任务 | 手写区与生成区的标题一起变为只读 | 一个操作在整个应用中生效 |
| 外部工具追加备注 | 两个区域显示同一份备注 | 外部工作直接进入当前任务 |
| 外部工具尝试修改已冻结标题 | 修改被拒绝，原标题与版本保留 | 应用的规则持续保护人的工作 |

本次实录用公开脚本客户端验证 AI 可接入的工具入口。大模型需要经工具适配接入；自主 Agent 操作的效果将另行评测。[演示视频](demo/README.md)的 00:41 起展示上述过程，具体请求与读回见[验证报告](VALIDATION.md)。

## 给开发者的一套共同入口

**业务规则写一次，界面和 AI 工具一起使用。** 应用声明有哪些对象、字段和动作，以及它们的类型、校验和授权。手写控件、生成控件和公开客户端读取这些声明，修改都进入应用实际的业务处理。新增一个能力时，开发者可以把它同时开放给界面和工具调用。

**AI 能知道当前允许做什么。** 客户端可以发现本次应用实例提供的资源、动作、参数和位置单位，读取当前数据版本，再提交操作。版本已变化或参数不合法时，应用返回明确结果，调用者可以重新读取后处理。

**界面能随着工作调整。** 生成区接收引用已声明组件、字段和动作的结构。结构不合法时保留原界面；具有相同稳定 key 的控件可在调整结构时接续草稿。开发者写的界面与生成界面可以并存。

模型与 Agent 框架由应用开发者选择。CJGUI 提供可复用的应用接口和客户端，开发者可以按自己的产品接入模型、组织任务，并保留人的直接操作入口。

## 为什么用仓颉实现

组件、布局、场景、控制器、业务数据与共享协议主要由仓颉实现。类与接口划分职责，泛型集合组织组件和资源，Option 与结果结构表达缺失、拒绝和失败。版本与文本位置单位在接口中明确传递，仓颉单元测试覆盖业务规则和异常请求。

macOS 使用窄 Objective-C 桥接接入 AppKit 窗口、系统文本服务和 Metal 绘制；鸿蒙使用 ArkTS 薄宿主、XComponent 与 OH_Drawing。排版缓存、纹理复用和视口虚拟化减少重复工作，首页实录展示了真实应用的列表滚动和 Markdown 预览。

外部 GUI 框架源码用于借鉴实现思路。CJGUI 的构建和运行未引入 Qt、SDL、GPUI、Flutter 或 Slint 等 GUI 框架依赖；系统服务沿平台桥接接入。

## 自选命题的区别

我们核对了 Cangjie-TPC、cj-awesome 及邻近项目。CJQT/CJQT6 提供 Qt 绑定，three.cj 面向 3D 引擎，CangjieMagic 提供 Agent 开发框架。CUI/苍翠已经有仓颉声明式、自绘、状态和组件等实践。

CJGUI 的选题重点是把**人的直接操作、AI 工具调用和运行时界面生成**接进同一套应用数据与规则，并交付普通消费者、公开客户端和演示。这一组合是我们判断选题差异的依据。项目逐项比较、来源与核查范围附在[查重说明](DUPLICATION_CHECK.md)，供评审复核。
