## 完整交付

一个不了解实现的开发者或外部 Agent，拿到公开接入说明、通用客户端和应用发出的 descriptor，就能发现对象/动作、读取当前选区和片段、修改并处理冲突。人使用同一文档视口看到结果、继续编辑与保存。正常消费无需研究测试脚本、猜 socket 字节格式或为每个样例编写一个新客户端。

同时将多行编辑的过渡平台控件整理为一致的文档视口：焦点切换、滚动、字体变化和外部改动不能让活动/非活动文档出现两套文字位置与状态。继续仓颉核心、自绘/Metal、窄平台桥接；系统文字整形与输入服务可用，完整富文本、聊天产品、MCP/所有模型适配和发布稳定化均不成为本阶段前置。

## 连续实施的能力

### 1. 通用客户端与可发现的开发者入口

将现有客户端整理为可复用、可导入的轻量 API，并保留易用 CLI。提供发现、授权上下文、变化、范围读取、动态操作与结构化结果；类型、UTF-8 解码、版本和错误由通用层处理。业务动作仍从应用描述发现，不内置通知/规则/文档 ID。具体 Python 包组织由执行 AI 决定，避免为了 SDK 引入重依赖。

公开帮助清楚说明如何取得并使用私有 descriptor、如何发现参数/版本/位置单位、如何读回以及如何处理过期、权限拒绝、连接关闭与不支持的协议。CLI 支持适合脚本的结构化输出和可识别退出状态；正文参数可从文件或标准输入传入，避免中文、多行和 shell 转义成为调用障碍。capability 不出现在普通诊断或公开示例中。

descriptor 或应用接入说明应能指向匹配的客户端/协议说明及兼容版本。不要在描述文件中携带让客户端任意执行的命令，也不增加模型运行时。启动、关闭与重启后的 descriptor 生命周期和客户端错误要可解释。

提供一个正常包消费的简短开发者入口：定义组件/文档与操作、打开窗口、按需开启连接、调用公共客户端。公开说明是验收输入的一部分；不再让新调用者从私有测试提取协议。

### 2. 文档视口与输入、滚动的一致性

延续当前无平台文档 owner，把可见行片段、视口偏移、选区与光标位置统一到可组合文档视图。使用必要的平台行排版服务生成度量/字形布局，文字仍可通过 AppKit 绘制适配自绘；无需本轮另写 GPU 字形引擎。

活动/非活动多行节点应消费同一文档快照和视口信息，正常显示不再依靠把完整 NSTextView/NSScrollView 作为另一套独立可见编辑控件盖在节点上。输入代理保留必要输入法/键盘职责；原生对象、文档业务和页面布局各有明确归属。可分步迁移，过渡路径仍如实标注，未接通前不要声称统一自绘完成。

验证跨行光标/选择、滚动后失焦再聚焦、两个文档来回切换、resize/字体变动、外部片段修改后继续输入；视口偏移与选区不能丢失或串文档。对超过一屏的内容，只布局/绘制所需行片段及缓冲区；给出适度的可见行数、提交次数等证据，不发明固定帧率承诺。

### 3. 有界批量片段与可靠保存

补齐同一文档、同一已读版本下的多段互不重叠替换。采用明确的批次规则：在原始文本坐标上验证全部范围/授权/边界后一次提交，失败时不部分修改；一个批次一个可撤销操作。用通用描述/客户端消费它，限制批次长度和总数据量，正确处理重复/重叠范围与过期版本。授权内屏外片段直接操作，不要求逐段滚动。

保存路径先复现新目标并发创建与两个协作实例竞争，不用用户文件测试。新目标发布不能覆盖抢先创建的文件；已有目标的协调、外部变更检测与保证边界要明确。可复用既有进程协调经验，不能宣称普通 rename 可以对所有不合作编辑器实现原子比较交换。失败时保留最后有效文件及内存草稿，保存的快照版本和未保存标志正确。

补跨端使用周期：人在窗口形成跨行选区，公共客户端读范围与版本后替换，窗口更新，人继续编辑和撤销/重做，再保存/重开。另测人先改后的过期拒绝，以及两个文档对象不串操作。不能以独立 headless 测试与独立 GUI 键入各自成功替代这条连接周期。

### 4. 真实独立消费与交付

准备临时数据与当前正常应用/无窗口实例，给一个无实现上下文的 Luna/Terra 验收 Agent：公开接入文档、客户端入口、应用 descriptor 和自然语言目标。它可以运行 --help、导入公共 API、阅读公开示例；不读实现/测试/阶段日志，不提供预知资源 ID 或请求序列。覆盖文档范围读取、有效替换、过期拒绝、重新读取，以及至少一个既有表单领域的动态发现/调用。

验收失败先判断是协议缺口、说明缺口、客户端缺口、权限/环境限制还是业务行为失败，不把“Agent 猜不出帧”当成框架必须暴露更多内部细节。阶段目标是别人能用，给正确公开入口是交付内容。至少一个正常 UI 默认无连接，启用连接是应用选择。

按 AGENTS.md 做相关 core/文档/客户端/真实 socket、生产输入/native 探针、正常包构建和必要 GUI 验证；图覆盖不足以源码与行为补证。保留图片等未受影响的既有结果，不每个内部步骤重跑全部。公开 API 保持 experimental，修改协议或客户端需有清楚的兼容/失败策略。
