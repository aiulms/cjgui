## 持续完成的工作

1. **补公共文档消费入口。** 先核已有typed/observer/快照入口，已有的直接扩展或接通，不另造平行客户端。沿现有text_document声明和公开字段获得目标文档版本、正文范围、endpoint/stream/绑定身份，提供可复用的文档读回、范围修改及已有历史动作入口。聚合版本、资源投影版本和正文版本明确分开；不要按应用名、7101等ID或“所有INVOKE都同一版本”猜测。调用者应能把一次明确读取的目标快照交给后续操作，服务端CAS仍决定是否接受。已有低层接口与provider兼容保留；只有真实缺少共同元数据时才作最小共同声明增量并说明兼容范围，不预设升级协议。
2. **把失败和回执做正确。** 复用现有解析，严格识别协议允许的布尔、版本、owner/范围与具名拒绝，畸形/重复/矛盾字段不能当成功。失效快照、换endpoint/绑定、错目标、readonly/未授权不得静默改目标或权限。一次调用只发送一次修改；发送后的超时/解析失败与明确拒绝分开，未知结果不自动重发。新读回可供调用者重新决策，不能内部刷新CAS后偷偷重试。使用既有64KiB范围/快照边界，不通过全文复制、轮询整上下文或每操作增加不必要往返来掩盖版本问题。未知资源类型具名不支持，不强行当文档。
3. **普通源码与SDK均能使用。** 在原公共目录维护一个用法入口和简短示例，覆盖读取文档、显式修改、冲突处理与继续读取；说明历史/保存仍由真实workspace或应用声明提供。把公开consumer接到该入口，移除本轮必要路径中的重复解析胶水，不清扫无关旧脚本。使用现有creator、构建、exporter和manifest；只补文档消费所需的公共模块/说明/示例，必要时补runner接入，不复制验收探针和大产物。支持从一个普通含空格包外路径使用，不依赖指导会话路径、私有CASE、未声明PYTHONPATH或根树偷渡源码。保持experimental稳定性声明，不发布、不Git提交。
4. **一次汇合交付。** 新公共代码/导出载荷确有变化后，汇合导出唯一新候选并保留ad7935回退；如只复用已有入口则不造同内容SDK。核实际编译/运行输入。一个普通文档窗口的两资源场景即可承接新客户端：独立读A/B，针对A的一次外部范围修改，B正文/版本不变；旧快照拒绝不写入；已有Undo/Redo、免重点击原生续写、实际文件保存和正常退出。按本次真实改动合并操作，不重复剪贴板全矩阵或另跑Mixed/Rules完整链。新客户端的目标绑定与结果解码由此成为普通可用能力，不只交离线探针。

## 分工、反例与验收投入

Terra负责公共版本/身份语义、严格解码和必要共同接口完整块；Luna负责SDK/公开示例/正常消费完整块，主执行先冻结接口再让Luna接入，双方写集明确。继续复用已有子代理；确有上下文故障可替换为同指定型号的短上下文子代理，先停原工作，不能形成多主线或给子代理另设监控。图工具先用；Cj覆盖不足按已知事实局部读源，不反复查空图。

优先用上一包真实原响应作兼容输入，另用有区分力的反例核错误版本域、畸形回执、目标/endpoint变化和未知结果不重放；服务端拒绝契约未改则复用适用旧证据。客户端/脚本按影响做针对性检查；有Cj/Native改动才执行相应构建与反例，不把所有词展开为矩阵。正常链的期望正文/版本从独立输入算出，不能让新客户端的输出同时充当oracle。
