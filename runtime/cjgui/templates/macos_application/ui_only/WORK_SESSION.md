# 可选工作会话

默认运行不创建会话文件、端点或服务器。需要保留本地工作时，运行：

```sh
./run.sh --work-session /absolute/path/local-work.cjwork
```

用“保存工作会话”保留注释、计数与业务版本。退出后用同一路径重新运行，即可继续工作；新窗口与渲染身份由当前进程重新创建。未保存的更改会阻止普通关闭，可保存后关闭，或显式选择“放弃会话更改并关闭”。

应用自己定义 `ui-only.note-counter.v1` 载荷，使用 Experimental 的 `CjguiComposableUiWorkSession` 提供有界载入、校验后采信、原子保存和持久基线。注释上限为 8192 UTF-8 字节，计数为 0–1000000，业务版本为 1–1000000000000；外层文件上限为 65536 字节。界面版本、native 窗口、端点和票据不进入文件。

格式或应用载荷不合法时，启动拒绝并保留原文件。保存复查所载入的原字节，检测到外改时拒绝覆盖；沿用文件绑定的协作锁并发边界。失败保存保留当前注释和旧文件，只有成功保存才更新持久基线。文件带 schema、版本与字节长度校验，没有校验和或防篡改承诺。该能力独立于界面结构文档，不会隐式应用其他应用的业务草稿。
