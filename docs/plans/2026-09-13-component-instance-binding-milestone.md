# 大阶段：可复用组件实例与绑定生命周期

2026-09-13；原执行任务Terra/xhigh、原目录。目标是开发者能把同一组件多次组合到应用中，动态插删重排后仍有稳定身份、正确命令和人机接续，不靠复制全局编号与注册代码。

## 复核与方向

上一阶段接受scope编码重排、陈旧快捷键/AX拒绝、焦点恢复与公开命令初版的已验成果。**未接受无条件完整验收**：controller probe曾退出69（逐层Escape收尾），无改动重跑两次成功不能解释根因；成本只有一次交互及两点进程读数，未覆盖原计划重复负载。两项明确承接本阶段，不改名清零。

源码显示组件仍依赖调用方手写nodeId，命令声明只追加且全窗口拒绝相同快捷键，即使focusScope不同。这对于单个固定页面可用，对重复组件、销毁重建与当前焦点内命令复用存在实际限制。先用两个或三个同类编辑区域实例复现开发者需要的行为，再提供最小公共能力，不照搬其他框架整套响应式/插件系统。

六主线取舍：布局、渲染、资源和正常包已有真实消费；文字/语义已有共同操作和代际保护。当前优先让这些能力能被不同开发者重复组合，继续保住输入/AX一致性，长文本尾部限制不阻塞本阶段。下一候选为正常应用体验与系统输入验收，或经本轮证据确定的性能瓶颈。保持仓颉/self-draw/GPU/窄native与外部接口路线。

复用DESIGN_INTENT_INDEX中的composable_ui、window/controller、层宿主、命令声明、共享编辑表单契约与normal Host。历史布局状态归属/父子销毁/平台泄漏教训用于约束方案：组件组合不是第二内容owner，生命周期不依赖native对象，测量/渲染缓存可丢弃，旧Action Router摘要和Bool链不复活。

## 整体交付

1. **必要旧项**：给Escape退出69加入能区分事件捕获scene/焦点/scope、入队顺序、pump预算与controller状态的诊断，构造确定性延迟/交错回归，区分平台事件尚未入队与旧scene拒绝、错误层关闭。保留原失败证据；无证据不增加sleep或放宽断言。可独立组件API工作同步推进，受其影响的层接续验收在根因解决前不标绿。
2. **组件实例身份**：提供仓颉侧可组合实例/局部key或等效构建上下文，让同一组件函数重复使用而无需用户手工分配全局数字区间。身份以稳定业务/实例key而非数组下标恢复；显式duplicate-key错误，不静默重用；销毁再建须区分生命周期，陈旧事件/AX不能串到新实例。保留现有低层node API，不要求一次迁移所有消费者。避免未检测哈希碰撞、无界全局ID表与每次build生成全新identity；选择方案写清界限即可，不建治理台账。
3. **绑定生命周期**：组件的事件/命令声明随实例可更新、撤销、销毁，不能反复重建累加注册或保留旧target。复用现有controller执行，状态与动作仍由真实owner管理。允许不同互斥焦点范围使用同一快捷键，规定当前焦点/顶层模态与global fallback优先级；同一作用范围的歧义应明确拒绝。更新绑定须与接受scene一致，失败恢复保留上个有效集。保住Cmd-A/C/X/V与marked text优先，不为样例写native分支。没有快捷键的菜单动作如需支持，应与动作声明分离，不填伪快捷键。
4. **通用组合消费**：至少做一个可复用编辑区/字段组，在同一窗口并排或列表重复使用，支持新增、删除、重排、临时隐藏恢复；另一个不同业务的正常消费者复用该公开能力。例：三个不同记录的编辑区，各自局部编辑/撤销或操作，聚焦后相同快捷键只作用当前实例，删除某组不会使旧输入修改邻组。外部按既有授权修改其一，本地接手与读回保持对应；不把视觉focus当外部权限。应用不需新增native代码或复制框架runtime。
5. **独立开发者验收**：Luna/Terra子代理只按公开README/新API说明编写一个重复组件消费、运行并实际触发命令/动态移除/读回。统计调用方需要声明的身份、绑定、生命周期代码，记录真正减少的重复与仍需手动维护的内容；不能仅以行数少称框架成熟。核心/普通界面不强制启用外部connection。

## 验收及成本

以实际不同实例与旧事件交错检验身份；覆盖挂载/销毁循环、重复key、同键不同scope、禁用/模态、绑定替换失败、Escape逐层、旧AX/快捷键与公开owner接续。按风险跑相关core/client/runtime、controller/布局/native与公共API扫描，新增测试必须针对行为，不机械镜像实现。

补上一阶段重复交互成本：预热后至少30轮焦点切换/开关层/组件增删重排/命令，记录端到端分布、build/layout/submit、队列高水位和AX通知；无业务变更导航不能触发全文领域构造，销毁循环的绑定/身份/缓存数量与运行CPU/RSS应有恢复证据。不要用单次idle或GET统计替代。最终两个bundle及独立消费按最终源码一次收口；无变更不重复整套。

系统中文IME/VoiceOver仍待系统级验证，保留上一阶段具体人工步骤。能可靠操作真实系统路径则补证，不能则如实记录，不用AX树/程序化marked text替代，不重复切换系统或更改锁屏设置。普通未验项不阻止本阶段独立能力。
