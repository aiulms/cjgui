# macOS consumer tests and application lifetime

Use `native/scripts/verify_cjpm_mac_testing_link.py --runtime FRAMEWORK --consumer APP --output OWNED_OUTPUT --filter FILTER` after selecting the Cangjie toolchain. It uses an isolated target, the shared four-member testing renderer archive and the standard Cangjie unittest entry. The application-only `cjgui_macos_application_launcher` interposer is excluded. Production `native/lib`, the consumer's ordinary `target` and its normal launcher remain untouched. The temporary graph is retired in `finally`; `--keep-build` retains one owned graph for diagnosis.

The driver supplies `cjguiMacosOwnerTest({ => ... })` in the consumer test package from the framework's single `src/macos_owner_fixture_test.cj`. Wrap a window test body in this fixture: AppKit main serves existing dispatch, a managed owner runs the test, and main stays alive until the owner's `finally` completes. A scalar loop-ready handshake prevents the owner task from starting on AppKit main before that loop has entered. An exception propagates to the standard test runner after cleanup. The ten-second fixture watchdog is a failing process, never a successful early exit. Test-only native hooks are absent from production archives.

For asynchronous scene acceptance, use a bounded monotonic deadline and the real accepted-scene predicate. A fixed number of `pumpOneTurn()` calls is not a wall-clock completion bound: a pending worker can legitimately make those turns return immediately. Keep normal Host waits inside the predicate loop; do not insert sleeps, retry a failed test in another process, or replace the accepted predicate with submission. Freeze the consumer's dependency sources as well as the framework, so a changed form declaration cannot consume a stale compiled domain. The 2026-10-24 same-process evidence and the two-test fixture adoption diff are in the Sol continuation handoff; the original 92-case log remains separate.

`macos_consumer_owner_fixture_test.cj.in` is a normal Mixed consumer example. It accepts the help dialog, intentionally raises one named exception and verifies that the original exception survives `Host.close()`. Poll a non-throwing accepted-node query until a bounded deadline; a helper that throws when a node is absent cannot itself be a wait predicate.

`CjguiMacosApplicationHost.close()` and `CjguiMacosApplication.close()` are final application shutdown. Do not close one Host and create another as a reopening fixture. For window close/reopen, keep one `CjguiMacosApplication` alive with a main window, call `requestClose(peerIdentifier)` for the peer, then `openWindow(...)` on that same application. `ordinaryBudgetExceptionsAndSupportedWindowReopen` exercises this contract, default/shared budgets, exception cleanup and conflicting caller budgets. It does not reset AppKit globals.

DS's original same-source unittest/launcher crash and the exact one-variable relink comparison are retained in the Sol ordinary-host evidence. The relink reports `print fixture target not accepted` with test exit 1 instead of an exit-0 process termination while the runtime was still decoding the exception stack. That underlying fixture assertion is separate from a successful modal return.
