## 目标与取舍

让普通开发者组合多个带菜单的动态组件、虚拟列表和文档编辑区后，局部修改仍保持快速反馈，外部批量修改不拖住其他窗口，工作停止后资源和刷新活动能够收敛。交付真实框架优化及正常应用消费，不止补计时、优化宣传样例或另建基准专用运行时。

源码显示当前刷新在 `buildUi → resolveCandidate → cloneForWindowCandidate → layoutWithMetrics → sameRenderedScene` 后才判定无需 native 提交。它是测量入口，不是已经证实的瓶颈。上一布局阶段显式复用在部分负载有收益，结构签名和某些全局变更存在回退；不得未经测量扩大缓存或直接删掉保证隔离的复制。

复用 [设计意图导航](DESIGN_INTENT_INDEX.md) 中的可组合窗口、唯一布局投影、稳定身份/引用事务、显式布局复用、文字纹理缓存、指针合并、单应用调度和真实 owner/CAS。继续落实 [避坑研究](../research/gui-framework-pitfalls-intelligence.md) 的盲目重绘、重入和状态归属教训，以及 [运行架构研究](../research/ai-native-gui-runtime-architecture-intake.md) 的高频视觉更新与业务修改分工。旧值模型仅作对照，不复活旧审计链，不固定外部编码。

## 必须完成的工作

1. **建立正常路径成本画像并据此实现优化。** 在当前正常消费者可复用的场景中，分辨声明构建、身份/引用、候选复制、布局/测量、native staging/提交的耗时和工作量；已有计时是毫秒，不足以判断小负载。沿用 MonoTime 纳秒或合适的 native 单调时钟，避免不同钟域直接相减。按真实热点选择一条或少数相互关联的通用优化，完成实现、正确性对照、普通消费和导出。不要每个环节都造缓存；计时可用实验诊断入口，公共 API 不为内部统计无端扩张。
2. **局部变更与混合负载。** 覆盖稳定树的局部文本/字段修改、动态列表插入删除及滚动、弹层开关、窗口大小/字体等全局失效，以及一个窗口接收公开批量调用时另一个窗口继续输入/滚动。先界定实际热点在 controller 还是框架，不能将样例减少内容当框架提速。只读观察/无变化轮次应保持既有不重建、不提交约束。优化后语义、命中、焦点、capture、锚点和实际 owner 必须与正确的接受场景对应；不得跳过业务校验、已接受版本或失败回滚来换速度。
3. **必要旧问题随主线处理。** 素材中按钮出现“撤销 撤销”“选择 选择”，先定位 label/value 的可视呈现与语义用途，修复真正负责该行为的通用组件/绘制或消费者声明；不要全局删 value 或破坏表单标签、当前值、无障碍及外部上下文。按真实触发补针对性回归。前台可用时，在同进程多窗口正常入口做 A/B 切换、分别操作、关闭 A 后 B 继续；受控日志不替代此项。屏幕不可用则保留未验并继续性能/代码工作，不让它阻塞独立能力。
4. **接受、失效和收敛。** 新增复用或快速路径必须在拒绝候选、异常、资源异步完成、resize/scale、目标删除重建和窗口关闭后保持正确；只测试本次影响的边界。复用既有有界策略并实测相关 retained/pending/队列变化及工作结束后趋稳，不声称这些计数等于总内存。多窗口使用同一 application 调度与独立 owner，不能另开进程冒充公平性。

## 验收标准

- 开始时保留当前源码基线和同条件正常路径数据；在同进程或严格匹配的构建/输入/缓存条件下比较。典型小/中/大场景，局部、全局和混合负载每个适用条件至少30有效样本，正确性断言在计时之外。报告 p50/p95、工作量、输入规模和构建指纹，不把0ms或计数减少当时延收益。
- 至少一项有代表性的通用路径取得有证据的实际改善；非目标全局负载不得隐瞒回退。先选路线、测量，再实现；若实现未获收益，调查并修正或撤回无效策略，同时推进独立工作。不能仅改成“不作时延声明”就宣布性能目标完成；结构性路线仍无收益则带具体对照及时升级指导。
- 明确 CPU 各阶段、提交、GPU 完成与屏幕实际呈现的区别。若现有可靠 native 完成证据可复用则关联观察，不为此新造完整物理时延实验；帧预算只作设计目标，不能引用 Zed 未同条件数字宣称追平。
- Luna 做有意义的受影响核心/窗口/消费者测试和必要 RED→GREEN，Terra 审关键衔接与风险；同 cjpm target 的 build/test 串行。沿用已证实可用的 Cangjie 1.1.3 + MacOSX15.4 SDK，核实 runner 的实际选择，避免默认旧工具链导致伪回归。相关构建、公共声明/边界扫描、diff 检查按 AGENTS 完成，不重复无关全量矩阵。
- 最终源码在含空格独立路径正式导出并实际消费受影响的公共能力，保留 source/preview/binary 与原始日志。保持已补齐的 LICENSE/NOTICE 随包。源码、正常应用、真实公开调用、实际模型、前台操作、发布分别记录。
