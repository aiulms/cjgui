# 按需风险参考

更新：2026-09-11。只在对应变更时查阅，不是逐轮检查表或暂停清单。

具体工程教训见[传统 GUI 框架避坑原文](../research/gui-framework-pitfalls-intelligence.md)；旧 guardrail 的禁止实施语句已由当前 AGENTS.md 取代，事件重入、盲目重绘、输入法、平台抽象等风险并未退役。指导阶段选择时按相关章节对照源码和证据，不只检查本表是否有同名条目。

| 风险 | 针对性处理 |
| --- | --- |
| 画面、语义和内容不一致 | 查真实状态归属与版本；通过实际读写、显示交叉验证 |
| 外部请求误解选择/草稿 | 明确文档、对象与选择范围；读取当前编辑状态 |
| 旧请求覆盖人的新修改 | 相关版本检查，拒绝/重读/显式合并 |
| 可见性被当作权限 | 分开判断授权与业务条件、视觉定位条件；复用已有授权 |
| FFI 资源泄漏/悬空 | 明确创建、持有、释放及失败释放路径，针对性探针 |
| AppKit 线程或关闭时序 | 按平台线程执行，验证正常关闭与目标失效 |
| 包构建与探针不一致 | 样例消费实际库产物；不能只临时复制少量源码编译 |
| 只剩审计摘要 | 找真实业务操作和应用入口，停止增加同构包装 |
| 语义更新过重 | 按范围查询、合并变化，不把每帧/每次击键变成模型调用 |
| 文本/IME 被低估 | 区分基础文字、编辑、复杂排版；只实现阶段所需范围并真实验证 |
| 像素断言过度脆弱 | 使用与语义相符的视觉检查，说明平台、字体和环境条件 |
| 公共接口过早固定 | experimental 标记、真实样例；稳定承诺与破坏性变更另做明确决定 |
| 外部系统兼容性被夸大 | 分别标记操作接口、对话会话、变化获取的实测支持 |
| 治理再次膨胀 | 合并重复规则，默认入口短；以完成实际工作衡量进展 |

第一阶段不解决所有长期风险。未触发项不要求 preflight，已确认的工程底线也不能被省略。
重大风险按 [AGENTS.md](../../AGENTS.md) 处理，阶段内可解决的问题由执行 AI 自主完成。
原详细风险分析仍可按主题检索：[历史快照](../archive/2026-09-11-direction-governance/README.md)。
