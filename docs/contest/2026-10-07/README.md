# CJGUI 初赛材料导航

CJGUI 是以仓颉为核心的自绘 GUI 框架，面向开发桌面工具、鸿蒙应用及 Agent 工具的开发者。它让窗口、生成面板和授权外部接口使用同一份业务数据与操作规则。本次为 macOS 开发预览。

## 阅读顺序

1. [项目提案](PROJECT_PROPOSAL.md)：用户、问题、方案和交付。
2. [演示视频与素材范围](demo/README.md)：编辑器首页滚动、生成面板和鸿蒙样例。
3. [验证与复现](VALIDATION.md)：环境、560/560 框架、100/100 共享核心、96/96 客户端结果与限制。
4. [源码状态](SOURCE_STATUS.md)：候选清单及公开版本的差异。
5. [自选命题查重](DUPLICATION_CHECK.md)和[仓颉 AI 生态贡献](AI_ECOSYSTEM_CONTRIBUTION.md)。

统一作品提交模板提供填写后的 Word 与待签字 PDF；联系人及签字只在团队私有邮件材料中。作品采用 [Apache License 2.0](../../../LICENSE)，更新记录见 [CHANGELOG](../../../CHANGELOG.md)。

## 当前范围

仓颉核心、自绘窗口、组件与布局、共同业务操作、受约束的生成绑定及多个真实消费者已有实现。系统输入、跨帧选择、全平台稳定性和发行交付仍在推进。模拟器证据、客户端契约测试及普通应用集成分别记录。
